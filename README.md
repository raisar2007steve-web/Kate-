<!-- ████████████████████ SECTION 07 — GETTING STARTED ████████████████████ -->

<img src="https://img.shields.io/badge/07-GETTING%20STARTED-3fb950?style=for-the-badge&labelColor=0d1117"/>

<br/><br/>

> **⚠️ Early Development** — KATE.OS is actively being built. Star ⭐ the repository to follow progress and get notified on releases.

<br/>

**Prerequisites**

```bash
node  >= 18.0.0
python >= 3.10.0
npm   >= 9.0.0
```

**Installation**

```bash
# ── 01  Clone the repository ──────────────────────────────────────
git clone https://github.com/starly/kate-os.git
cd kate-os

# ── 02  Install Node dependencies ─────────────────────────────────
npm install

# ── 03  Install Python dependencies ───────────────────────────────
pip install -r requirements.txt

# ── 04  Configure environment ─────────────────────────────────────
cp .env.example .env
# Edit .env with your API keys and configuration

# ── 05  Launch development environment ────────────────────────────
npm run dev
```

**Docker (Recommended)**

```bash
# Build and run with Docker Compose
docker-compose up --build

# KATE.OS will be available at http://localhost:3000
```

<br/>

```bash
# ── Step 1  Fork the repository ────────────────────────────────────
# Click the Fork button on GitHub

# ── Step 2  Create your feature branch ────────────────────────────
git checkout -b feature/your-feature-name

# ── Step 3  Make your changes & commit ────────────────────────────
```
